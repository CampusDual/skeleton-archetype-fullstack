====================================================
CONTEXTO DEL PRODUCTO
====================================================

PRODUCTO

Gestión Inteligente de Inventario para Restauración

PROBLEMA

Los restaurantes suelen gestionar el inventario de forma manual o mediante herramientas desconectadas de las ventas y de la elaboración de platos.

Consecuencias:
- Falta de visibilidad del stock real.
- Roturas de stock inesperadas.
- Compras reactivas.
- Errores en la disponibilidad mostrada a camareros y clientes.
- Dificultad para analizar consumos y prever necesidades futuras.

OPORTUNIDAD

Crear una plataforma integrada que conecte:

- Inventario
- Recetas
- TPV
- Compras
- Proveedores
- Disponibilidad de platos
- Analítica

OBJETIVOS DE NEGOCIO

- Reducir roturas de stock.
- Mejorar la precisión del inventario.
- Reducir el tiempo dedicado a tareas manuales.
- Automatizar procesos de reposición.
- Mejorar la experiencia operativa del restaurante.

USUARIOS

- Responsable del restaurante
- Responsable de compras
- Gerente
- Camarero
- Cliente

HIPÓTESIS

- La automatización reducirá errores.
- Las alertas reducirán roturas de stock.
- La integración con TPV mejorará la operación.
- La analítica mejorará la toma de decisiones.

RIESGOS

- Recetas mal configuradas.
- Sincronización incorrecta del TPV.
- Inventario inicial erróneo.
- Dependencia de integraciones externas.

====================================================
INSTRUCCIONES PARA GENERAR EL USER STORY MAPPING
====================================================

Construye el User Story Mapping siguiendo la metodología de Jeff Patton.

Nivel 1 (Backbone)

Define las grandes actividades de usuario de extremo a extremo.

Por ejemplo:

- Configurar inventario
- Gestionar productos
- Gestionar recetas
- Registrar ventas
- Actualizar stock
- Gestionar alertas
- Reponer inventario
- Gestionar proveedores
- Analizar consumos
- Supervisar operación

Nivel 2 (User Activities)

Descompón cada actividad principal en tareas de usuario.

Nivel 3 (User Tasks)

Descompón cada tarea en acciones concretas.

Nivel 4 (User Stories)

Genera historias de usuario en formato:

"Como [tipo de usuario]
Quiero [objetivo]
Para [beneficio]"

Añade criterios de aceptación breves para cada historia.
